# Practice: review a translated technical PDF

This exercise uses a one-page **fictional** electronic datasheet authored by Scanfile and a real, uncorrected English-to-Spanish translation generated by Scanfile. The invented values do not describe a real component and must not be used for engineering decisions. The files contain no customer data. The original and review notes are shared under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Download both files into the same folder:

- [English original PDF](https://scanfile.online/samples/pdf/datasheet-en-es/datasheet-review-test.en.pdf)
- [Uncorrected Spanish result PDF](https://scanfile.online/samples/pdf/datasheet-en-es/datasheet-review-test.es.pdf)
- [Spanish review notes](https://scanfile.online/samples/pdf/datasheet-en-es/review.es.txt)

After installing the command-line tool as described in the [README](../README.md), run:

```sh
pdf-translation-review datasheet-review-test.en.pdf datasheet-review-test.es.pdf -o datasheet-review.pdf
```

Choose a new output filename if `datasheet-review.pdf` already exists. Open the result in a PDF reader. The original is on the left and the translation is on the right. This command arranges pages; it does **not** detect mistakes, verify meaning, or certify the translation. Review the source documents themselves if a page is too small or renders differently.

## What to look for

1. In the pin-identification section, compare the literal identifiers `IN` and `OUT` with `ENTRADA` and `SALIDA` in the result. A label printed on a device may need to remain literal, even when its meaning can be translated.
2. In the table, compare each symbol, row, column, sign, value, unit and footnote. In this particular sample, `I_CC`, `V_IH` and `t_PD` and the displayed numerical values were observed in the corresponding rows; check them yourself against the source rather than assuming that every output preserves them.
3. Compare “Supply current” with “Suministrar corriente”, and inspect the misspelling `pruea` in the translated test conditions. The Spanish wording needs technical and linguistic review.
4. Check negative instructions, test conditions and the header. The translated header renders `SCANFILE` as `ARCHIVO ESCANEADO`, which is not the original name.

The Spanish result has not been independently reviewed by a native speaker. This is one selectable-text page, not an OCR test, a quality benchmark, or evidence that other documents preserve their layout or values. Neither this example nor the review tool provides professional engineering verification. Use a qualified reviewer and the manufacturer's authoritative document for real technical work.
