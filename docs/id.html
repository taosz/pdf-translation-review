Periksa PDF asli bersama terjemahannya

Pilih dua PDF dari sumber mana pun. Baca masing-masing satu halaman: berdampingan di layar lebar dan bertumpuk di layar kecil. Pilih halaman yang sesuai lalu periksa nama, angka, tabel, dan maknanya.

Ini adalah pembaca visual untuk pemeriksaan manual. Alat ini tidak menerjemahkan, menyelaraskan halaman secara otomatis, menemukan teks yang hilang, memeriksa makna, atau menyertifikasi terjemahan.

Memuat pembaca PDF. Jika kontrol tetap tidak tersedia, periksa koneksi dan muat ulang halaman.

Contoh berisi teks fiktif bahasa Inggris dan Spanyol untuk latihan; contoh ini bukan terjemahan Scanfile dan tidak menunjukkan kualitas terjemahannya.

PDF terjemahan

Maksimal 50 MiB dan 300 halaman per file. PDF yang dipilih dibaca di browser ini dan tidak diunggah oleh pembaca ini. GitHub Pages menerima permintaan biasa untuk aplikasi dan kode PDF.js yang disimpan bersama halaman ini. PDF yang rusak atau dilindungi kata sandi mungkin tidak dapat dibuka. Tampilan dapat berbeda dari pembaca lain. Hapus kedua file setelah selesai.

Perlu menerjemahkan PDF terlebih dahulu?

Pembaca ini dikelola oleh pengembang Scanfile. Lihat penerjemah PDF Scanfile. Terjemahan adalah layanan terpisah yang mengunggah PDF dan mengikuti ketentuan uji coba dan kredit yang ditampilkan di situs.

Tautan berisi label kampanye tetap untuk statistik agregat; nama file dan isi dokumen tidak disertakan. Statistik Scanfile mengikuti pengaturan privasi browser.
